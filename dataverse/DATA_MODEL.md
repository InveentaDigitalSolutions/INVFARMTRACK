## Conventions

- **Every table's primary column is a Dataverse autonumber** — `SH-0001`,
  `PLT-0001`, and so on. These are generated by the platform and are not
  editable in the app.
- **Dates** use `Date only` behaviour where no time is meaningful. Storing a
  date-only value as `UserLocal` shifts it a day for downstream readers.
- **Deletes are referential, never parental.** A required lookup restricts the
  delete; an optional one clears the link. Cascade would make the relationship
  parental, and a child may have only one parent.
- **Composition is a relationship, not columns.** An input's guaranteed
  analysis lives in `Input Component` lines, so a product may declare any
  number of nutrients or active ingredients.
